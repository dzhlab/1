# 🎀 Система управления соревнованиями по художественной гимнастике

Веб-приложение для организации и проведения соревнований по художественной гимнастике с полным функционалом управления участниками, оценками и результатами.

## ✨ Возможности

### 👤 Управление участниками
- Регистрация гимнасток с указанием:
  - ФИО
  - Возраста
  - Клуба/Школы
  - Категории (Юниоры, Молодежь, Взрослые)
- Просмотр списка всех участников
- Удаление участников

### 🏆 Управление соревнованиями
- Создание соревнований с параметрами:
  - Название соревнования
  - Дата проведения
  - Категория участников
  - Выбор дисциплин
- Доступные дисциплины:
  - Скакалка
  - Обруч
  - Мяч
  - Булавы
  - Лента
  - Без предмета
- Удаление соревнований

### 📝 Выставление оценок
- Выбор соревнования и участника
- Оценка по трем критериям:
  - **E-score** (Execution) - Техника исполнения (0-10)
  - **D-score** (Difficulty) - Сложность (0-10)
  - **A-score** (Artistry) - Артистизм (0-10)
- Автоматический подсчет общей оценки
- Возможность редактирования оценок
- Просмотр всех выставленных оценок

### 📊 Результаты и рейтинги
- Автоматический подсчет итоговых результатов
- Таблица результатов с сортировкой по местам
- Визуальное выделение призовых мест (золото, серебро, бронза)
- Подиум победителей с медалями
- Детализация оценок по каждой дисциплине

## 🚀 Запуск приложения

### Простой способ
1. Откройте файл `index.html` в любом современном веб-браузере
2. Приложение готово к использованию!

### Локальный сервер (опционально)
```bash
# С помощью Python 3
python -m http.server 8000

# С помощью Node.js (http-server)
npx http-server

# С помощью PHP
php -S localhost:8000
```

После запуска откройте `http://localhost:8000` в браузере.

## 📖 Инструкция по использованию

### Шаг 1: Регистрация участников
1. Перейдите на вкладку **"Участники"**
2. Заполните форму регистрации:
   - Введите ФИО гимнастки
   - Укажите возраст
   - Введите название клуба или школы
   - Выберите категорию
3. Нажмите **"Зарегистрировать участника"**
4. Участник появится в списке ниже

### Шаг 2: Создание соревнования
1. Перейдите на вкладку **"Соревнования"**
2. Заполните форму создания соревнования:
   - Введите название соревнования
   - Выберите дату проведения
   - Выберите категорию участников
   - Отметьте дисциплины, которые будут в программе
3. Нажмите **"Создать соревнование"**

### Шаг 3: Выставление оценок
1. Перейдите на вкладку **"Оценки"**
2. Выберите соревнование из выпадающего списка
3. Выберите участника (доступны только участники соответствующей категории)
4. Выберите дисциплину
5. Введите оценки:
   - Техника исполнения (E-score)
   - Сложность (D-score)
   - Артистизм (A-score)
6. Общая оценка будет рассчитана автоматически
7. Нажмите **"Сохранить оценку"**

### Шаг 4: Просмотр результатов
1. Перейдите на вкладку **"Результаты"**
2. Выберите соревнование из выпадающего списка
3. Просмотрите:
   - Таблицу результатов с оценками по всем дисциплинам
   - Подиум с тремя лучшими участниками

## 💾 Хранение данных

Приложение использует **localStorage** браузера для хранения всех данных:
- Данные сохраняются автоматически после каждого действия
- Данные сохраняются локально в браузере
- При повторном открытии приложения все данные будут восстановлены

### ⚠️ Важно
- Данные хранятся только в браузере на вашем компьютере
- Очистка данных браузера приведет к потере информации
- Для использования на другом компьютере данные нужно будет ввести заново

## 📋 Системы оценивания

Приложение использует профессиональную систему оценивания художественной гимнастики:

- **E-score (Execution)** - оценка за технику исполнения
- **D-score (Difficulty)** - оценка за сложность элементов
- **A-score (Artistry)** - оценка за артистизм и выразительность

**Итоговая оценка** = E + D + A

## 🔄 Управление данными

### Удаление данных
- **Участники** - кнопка "Удалить" в карточке участника
- **Соревнования** - кнопка "Удалить" в карточке соревнования (удаляются все связанные оценки)
- **Оценки** - кнопка "Удалить" в карточке оценки

### Редактирование оценок
При повторном выставлении оценки для той же комбинации участник+дисциплина+соревнование, предыдущая оценка будет обновлена.

## 🎯 Рекомендации по использованию

1. **Сначала зарегистрируйте участников** - без них нельзя выставлять оценки
2. **Создайте соревнование** - укажите правильную категорию
3. **Выставляйте оценки последовательно** - по дисциплинам и участникам
4. **Проверяйте результаты** - таблица обновляется автоматически
5. **Делайте резервные копии** - скриншоты или экспорт результатов
