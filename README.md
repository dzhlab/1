# 🎀 Платформа управления соревнованиями по художественной гимнастике

Комплексная веб-платформа для организации и проведения соревнований по художественной гимнастике с полным функционалом управления соревнованиями, судейством и участниками в соответствии с **правилами FIG (Международной федерации гимнастики) 2025-2028**.

## 🎯 Новая версия - Enterprise Backend API

**Версия 3.0** включает профессиональный backend на NestJS с:
- RESTful API с Swagger документацией
- PostgreSQL база данных с Prisma ORM
- JWT аутентификация и авторизация
- Real-time обновления через WebSocket
- Модульная архитектура для масштабирования
- Docker поддержка

### Быстрый старт с Docker

```bash
# Запустить все сервисы (PostgreSQL + API)
docker-compose up -d

# Применить миграции БД
docker-compose exec api npm run prisma:migrate

# API доступен по адресу http://localhost:4000
# Swagger документация: http://localhost:4000/api/docs
```

### Ручной запуск

```bash
# 1. Установить зависимости
cd apps/api
npm install

# 2. Настроить .env
cp .env.example .env

# 3. Запустить PostgreSQL
docker-compose up -d postgres

# 4. Применить миграции
npm run prisma:generate
npm run prisma:migrate

# 5. Запустить API
npm run start:dev
```

### 📝 Профессиональная система оценивания (FIG 2025-2028)

Приложение реализует полную систему судейства согласно Code of Points FIG 2025-2028:

#### D-бригада (Difficulty - Трудность)
- **DB (Difficulty of Body)** - Трудность тела
  - 2 судьи (DB1, DB2)
  - Оценивают сложность элементов тела: прыжки, равновесия, повороты
  - Финальный DB = среднее арифметическое (DB1 + DB2) / 2

- **DA (Difficulty of Apparatus)** - Трудность предмета
  - 2 судьи (DA1, DA2)
  - Оценивают мастерство работы с предметом
  - Финальный DA = среднее арифметическое (DA1 + DA2) / 2

- **D-Score = DB + DA**

#### E-бригада (Execution - Исполнение)
- 4 судьи (E1, E2, E3, E4)
- Оценивают технические ошибки путем сбавок от 10.0
- Отбрасываются максимальная и минимальная оценки
- Финальный E-Score = 10.0 - среднее из двух оставшихся сбавок

#### A-бригада (Artistry - Артистизм)
- 4 судьи (A1, A2, A3, A4)
- Оценивают артистизм, музыкальность, хореографию путем сбавок от 10.0
- Отбрасываются максимальная и минимальная оценки
- Финальный A-Score = 10.0 - среднее из двух оставшихся сбавок

#### Штрафы
- Нарушения времени выступления
- Выход за границы ковра
- Запрещенные элементы
- Другие нарушения правил

#### Итоговый балл
**Final Score = D + E + A - Penalties**

- Автоматический расчет всех компонентов
- Визуальное отображение оценок каждой бригады
- Детальная разбивка итогового балла
- Возможность редактирования оценок
- Просмотр всех выставленных оценок

### 📊 Результаты и рейтинги
- Автоматический подсчет итоговых результатов
- Таблица результатов с сортировкой по местам
- Визуальное выделение призовых мест (золото, серебро, бронза)
- Подиум победителей с медалями
- Детализация оценок по каждой дисциплине

## 📖 Инструкция по использованию

### Шаг 1: Регистрация участников
1. Перейдите на вкладку **"Участники"**
2. Заполните форму регистрации:
   - Введите ФИО гимнастки
   - Укажите возраст
   - Введите название клуба или школы
   - Выберите категорию
3. Нажмите **"Зарегистрировать участника"**
4. Участник появится в списке ниже

### Шаг 2: Создание соревнования
1. Перейдите на вкладку **"Соревнования"**
2. Заполните форму создания соревнования:
   - Введите название соревнования
   - Выберите дату проведения
   - Выберите категорию участников
   - Отметьте дисциплины, которые будут в программе
3. Нажмите **"Создать соревнование"**

### Шаг 3: Выставление оценок (FIG 2025-2028)
1. Перейдите на вкладку **"Оценки"**
2. Выберите соревнование из выпадающего списка
3. Выберите участника (доступны только участники соответствующей категории)
4. Выберите дисциплину
5. Введите оценки от всех судейских бригад:

   **D-бригада (Трудность):**
   - DB1, DB2 - оценки за трудность тела (Body Difficulty)
   - DA1, DA2 - оценки за трудность предмета (Apparatus Difficulty)

   **E-бригада (Исполнение):**
   - E1, E2, E3, E4 - сбавки за технические ошибки (0-10)

   **A-бригада (Артистизм):**
   - A1, A2, A3, A4 - сбавки за артистизм (0-10)

   **Штрафы:**
   - Дополнительные штрафы за нарушения (если есть)

6. Все промежуточные и итоговый балл рассчитываются автоматически
7. Нажмите **"Сохранить оценку"**

### Шаг 4: Просмотр результатов
1. Перейдите на вкладку **"Результаты"**
2. Выберите соревнование из выпадающего списка
3. Просмотрите:
   - Таблицу результатов с оценками по всем дисциплинам
   - Подиум с тремя лучшими участниками

## 📋 Система оценивания FIG 2025-2028

Приложение использует официальную систему оценивания Международной федерации гимнастики (FIG) Code of Points 2025-2028:

### Судейские бригады

**D-бригада (Difficulty Panel):**
- **DB (Body Difficulty)** - 2 судьи оценивают трудность элементов тела
- **DA (Apparatus Difficulty)** - 2 судьи оценивают трудность работы с предметом
- D-Score = DB + DA (без максимального ограничения)

**E-бригада (Execution Panel):**
- 4 судьи оценивают технические ошибки
- Каждый судья выставляет сбавки от 10.0
- Отбрасываются максимальная и минимальная оценки
- E-Score = 10.0 - среднее из двух средних оценок

**A-бригада (Artistry Panel):**
- 4 судьи оценивают артистические аспекты
- Каждый судья выставляет сбавки от 10.0
- Отбрасываются максимальная и минимальная оценки
- A-Score = 10.0 - среднее из двух средних оценок

### Формула расчета

**Итоговый балл = D + E + A - Штрафы**

Где:
- **D** (Difficulty) - открытая шкала, нет максимума
- **E** (Execution) - от 0 до 10
- **A** (Artistry) - от 0 до 10
- **Штрафы** - дополнительные сбавки за нарушения правил

### Ключевые изменения 2025-2028

- Разделение D-бригады на DB и DA для более точной оценки
- Система отброса максимальных/минимальных оценок в E и A бригадах
- Акцент на баланс между трудностью, техникой и артистизмом
- Прозрачная система штрафов

## 🔄 Управление данными

### Удаление данных
- **Участники** - кнопка "Удалить" в карточке участника
- **Соревнования** - кнопка "Удалить" в карточке соревнования (удаляются все связанные оценки)
- **Оценки** - кнопка "Удалить" в карточке оценки

### Редактирование оценок
При повторном выставлении оценки для той же комбинации участник+дисциплина+соревнование, предыдущая оценка будет обновлена.

## 🎯 Рекомендации по использованию

1. **Сначала зарегистрируйте участников** - без них нельзя выставлять оценки
2. **Создайте соревнование** - укажите правильную категорию
3. **Выставляйте оценки последовательно** - по дисциплинам и участникам
4. **Проверяйте результаты** - таблица обновляется автоматически
5. **Делайте резервные копии** - скриншоты или экспорт результатов
